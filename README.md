# 知识梳理器

面向 Windows 与安卓手机、平板的本地学习应用，独立于具体课程。

## 当前状态与目录

- `README.md`：产品范围、验收目标和实施顺序。
- `src/domain/`：数据校验、阶段流转、评分与选文定位。
- `src/application/`：保存队列、分批讲解请求、存储/设备/AI接口。
- `src/ui/`：共享原文映射与安全公式渲染；旧页面源码保留，不再作为打包入口。
- `src/design/`：当前统一学习界面，多层分组、单题翻页、两种反馈模式、历史和局部疑问。
- `src/domain/workspace.ts`、`src/platform/workspace-db.ts`：统一学习空间校验、旧库只读迁入与事务保存。
- `src/application/workspace-backup.ts`：新学习空间备份及旧v1备份读取。
- `src/platform/prototype-server.mjs`：仅提供构建页面的原型服务。
- `src/platform/indexed-db.ts`：题集、作答、标记和会话的本地事务存储适配。
- `src/platform/browser-device.ts`：浏览器文件选择、文件导出及剪贴板适配。
- `src/platform/build.mjs`、`service-worker-template.js`：构建网页及离线页面资源。
- `src/native/`：Tauri原生入口、安卓工程、权限与图标配置。
- `src/platform/tauri-device.ts`：安装版系统文件选择、保存及剪贴板适配。
- `src/application/deepseek.ts`、`src/platform/tauri-deepseek.ts`：白名单上下文、流式事件解析与原生AI适配；Android DeepSeekPlugin负责密钥及HTTPS。
- `assets/`：应用图标等正式资源。
- `package.json`、`package-lock.json`：依赖和实际可执行命令。
- `tsconfig.json`：核心代码的 TypeScript 检查配置。

已接入题集导入、逐题或整套反馈、理解自评、历史、返工、局部疑问、分批复制、事务存储及备份导出/恢复。采用原生 Selection/Range、TypeScript、KaTeX 与 Vite；安装封装使用 Tauri 2。安卓0.3.1 ARM64包改为侧栏直接选择套题，并接入用户自有DeepSeek API Key、安全存储和原生流式问答。0.2.0已有安装/启动反馈；新版仍需手机验收及用户自行填入密钥后验证真实API。Windows安装包和Windows密钥适配尚未实现。下文包含规划及待设备验收的功能，不代表各平台均已通过。仓库只保存应用源码、必要配置和本说明；开发交接材料及本地数据不随源码发布。

现在只有一个学习入口，分组、题集、每一轮答案、题号、理解自评、标记、概括和提问草稿均自动保存。启动恢复上次题目或列表，正常保存不打扰练习，失败时才提示重试；分组仅用于整理展示，左上角侧栏可直接选择任意套题，不使用逐层返回。安卓返回键先关闭弹层、侧栏或选区，正常学习页面保存后回到桌面，下次点图标继续原页面。“更多”中的“退出”等待保存后回到桌面，不再询问是否保存，再开仍回原位置；不沿网页访问历史往返。重新练习会保留当前轮次，可从套题“学习记录”找回，已完成答案和自评只读。

电脑调试可运行 `node src/platform/design.mjs`，打开 `http://127.0.0.1:4175/`；可追加本机题集路径预载内容。此入口现与安装版共用同一套学习界面及存储，调试浏览器可切换桌面/手机尺寸，安装版按屏幕自动布局。浏览器扫描只检查用户选择文件夹中的JSON；安卓“扫描题集”自动查找公共存储中的JSON题集，首次需在系统页面允许文件访问，返回应用后继续查找，无需逐层选择路径。未授权时仍可手动导入。扫描只读，不修改或上传文件；其他应用私有的Android/data与obb目录不在可扫描范围。`node src/platform/design.mjs --build` 为该入口的独立网页构建检查，产物 `design-dist/`，不是APK。

删除题库：练习页“更多 → 删除当前题库”，或在“全部套题”列表点相应题库的“删除”，核对名称后确认。删除会一起移除该题库的当前/历史练习、疑问和AI对话，其他题库、API Key及手机中的原始JSON不受影响；已有备份不自动删除，需要时可手动恢复。删除前先完成本机保存，操作失败保留原记录；普通保存不能借此绕过历史保护。

分组支持至少三层并可继续嵌套，每套题保持一个长期入口。开始一轮时选择逐题反馈或整套提交，练习中保持该模式；每页一道题，可左右滑动或通过题号导航切换。选项整行可点，兼顾左右手；点选与理解自评原地更新，保留当前滚动位置；长按、拖选、滚动、滑动及点选高亮/公式动作时不修改答案，确认后锁定。

点击高亮或概念卡先看概括，再进入同处讨论；概括编辑草稿与未发送提问也会保存，并可选文继续追问。概括与答案、自评独立；不同题目及标记隔离，解除疑问不删除记录。安卓可在“更多 → DeepSeek 设置”填写自己的API Key，选文标记后进入讨论，输入问题并点“预览并发送”，确认本次内容后才请求官方服务；无需电脑中转。回答、实际用量和中断状态本地保存，之前的回答也可选文继续追问。“让AI概括”生成独立候选，用户采用后才更新概括，不自动覆盖手写内容。概括更新复用src/application/concept-summary.ts；可选ConceptSummaryProvider仍是独立扩展端口，当前实现通过已接入的AIProvider请求候选。未配置或断网时可继续做题、标记和保存草稿。

保存队列处理快速操作、失败重试和版本冲突；只有事务提交完成才视为已保存；界面不常驻显示内部状态，失败保留本页草稿并阻止退出。新库knowledge-organizer.workspace使用CAS防止旧窗口覆盖；首次升级只读复制旧knowledge-organizer.learning题库、历史、答案、标记及备注，保留旧标记/会话原始记录和旧库。学习空间及workspace-backup升级为v2，增加按标记隔离的用户/AI消息、完成/中断状态和实际用量；兼容只读迁入workspace/备份v1及旧knowledge-organizer.backup v1，旧Attempt/Backup格式不改写。恢复补入缺失记录、相同ID保留本机内容，同版本题集内容冲突整包拒绝。0.2.0预览页未落盘的内存无法在退出后恢复。

数据库适配与原型专用 localStorage 隔离，不自动迁入原型标记。数据属于当前浏览器或应用宿主；清除网站/应用数据会丢失记录，不能用临时网址替代正式安装与备份。浏览器配额与数据清理限制见 [存储管理说明](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)。

安装版保持一个学习入口。可自动扫描题集，也可用系统文件选择器导入题集/备份，并选择保存位置导出备份。扫描结果只列题集，格式不符的文件跳过，不展示校验报告。网页和公式字体随APK内置，本地学习不依赖电脑或公网预览服务。0.3.1新增题库删除，并将返回手势离开改为保存后将任务放到后台，不结束现有页面；用户报告的边缘返回后重开闪退尚未直接复现，不能视为已实机消除。手机返回重开、密钥安全存取、真实问答、扫描权限与升级恢复仍待用户复验。

将APK及自己的JSON题集传到手机，打开APK按系统提示允许该来源安装，再在应用中导入题集。此包最低Android 7、仅ARM64；这是构建配置，不代表全部对应设备已验证。正式使用请定期“导出备份”；后续升级使用同签名新版覆盖安装，不先卸载或清除应用数据。旧浏览器记录与安装版隔离，需要从旧入口导出备份再导入，不能自动读取临时网址的数据。

选文后点“标记选中的疑问”；跨题干、选项或解析时要求在同一字段重选。公式内部选择扩大为整式，也可点“标记整式”；暂不支持公式内部精细标记。整条选项可点击，已有选区或正在拖动/长按时拒绝改答案；取消选文后再作答。逐题确认或整套提交后锁定相应答案并显示解析，解析也能标记。

在“更多”中点“字号”打开14～30px滑条，拖动实时调整正文、选项、解析和概括文字及公式，不重建题目；偏好自动保存，旧字号设置尽量迁入。菜单字号、题目及学习内容不因调整而改变。

逐题模式确认本题后即可自评，整套模式统一提交后逐题自评；全部自评后完成。完成轮次的答案和自评只读，局部疑问可继续管理。返工按错题、不理解和未解除疑问并集建立独立题集，不覆盖旧成绩。每套题“继续练习”和“学习记录”可找回未完成与已完成轮次。

首次联网打开并等待“离线页面已准备”后，可断网重开同一地址；导入的题集和学习记录保存在当前设备，不发送到预览服务器。首次加载和可选练习题仍需网络；网页缓存与浏览器存储被清理后需要联网重开并用备份恢复。更新不强制刷新正在学习的页面，保存后关闭全部学习页面再打开即可使用新版本。手机浏览器检查不能替代最终APK验收。

“备份”在支持系统保存的位置等待写入完成；其他浏览器交给下载管理器并提示检查文件。“恢复备份”先展示数量与保留本机规则，再确认原子恢复。保存失败可重试，或先导出本页备份，再通过“重新读取”明确撤销尚未保存的修改。系统强杀可能打断尚未完成的写入；正常退出会等待保存，失败时保留页面供重试。

## 产品定位

面向 Windows 电脑、安卓手机与平板的本地学习执行工具。本地核心负责文件导入、交互答题、疑问标记、本地保存和复制输出；可选 DeepSeek API 支持就地提问与追问。无需 ChatGPT 插件、OpenAI API、用户登录或自建云端服务，不填 DeepSeek 密钥也能使用全部本地功能。

## 第一版功能

### 导入与答题

导入有明确版本的结构化题目文件。题目至少包含稳定ID、题型、模块、知识点、题干、选项ID及文字、标准答案、解析；有原题时保留原编号、原文和来源。第一版只接受约定格式，不自动识别 PDF、Word 或扫描试卷。文件和题目内容由外部 AI 或人工制作；应用校验格式与答案引用，不把格式正确等同于知识正确。

同轮多题逐页展示，题数和选项数由数据决定，支持判断、单选、多选，左右滑动和题号导航切题。多选完全匹配评分，漏选或错选均判错。正文和公式支持分式、上下标、共轭横线等。

### 反馈模式与理解自评

1. 作答阶段只展示题目和选项，不泄露正确答案与解析，填写过程及时保存。
2. 开始一轮时选择逐题反馈或整套提交。逐题确认后锁定本题并同页显示解析、自评；整套模式待全部作答后统一确认并锁定，再逐题查看解析与自评。
3. 在各题解析下选择“理解了／仍不理解”。这表示阅读答案解析后的理解程度，不表示答题前的自信。
4. 所有自评完成后结束本轮，形成只读记录；重新练习创建新作答，不覆盖历史。

保存答题阶段、解析自评阶段和完成阶段。未选择的自评是“未评价”，不得当成“不理解”；保存失败须保留填写内容并允许重试。

### 局部疑问标记

题干、选项和解析均支持文字选择及疑问标记。Windows 用鼠标选择，安卓用长按和拖动选择手柄。用户只需标出片段，不必提前说明哪里不懂。允许选填备注、单题多处标记、查看修改和删除标记，并立即本地保存。

提供疑问列表，保留原文和所属题目上下文，单条或批量复制。存在未解除的局部疑问题目即进入待讲解列表，即使该题答对或整题自评理解也不能忽略。

完整公式支持整体标记；公式内部逐符号选择是待原型验证能力，不作为已经支持的功能。验收时必须分别检查普通文字、文字与公式相邻位置、完整公式，以及手机选文与滚动的冲突。

### 成绩与 AI 交接

显示每轮与各模块正确率、自评理解率及待讲解题。区分答错但理解、答对但不理解、答错且不理解和局部疑问。

“复制讲解请求”至少包含题集名称与版本、原题编号（如有）、题干及选项、用户答案、标准答案、理解自评、疑问片段及上下文；按需附原解析。用户粘贴到任意 AI 客户端即可提问，无需AI记忆此前选项。提供单题、错题与疑问题、完整记录三个复制范围，长内容可分批复制，剪贴板失败提供可选择文本。输出明确哪些是题目数据，哪些是讲解要求。

答对且理解且无疑问可略过；答错但理解简要纠错；不理解或有局部疑问须针对性讲解。待讲解列表为答错、不理解或有疑问的并集。

### 本地数据

本地保存题库、作答、阶段、自评、标记和历史，支持重开恢复、历史回看和返工练习。重复导入及版本变化必须明确处理，不让标记错贴到修改后的题干。支持备份文件导出与导入，第一版通过文件在设备间转移，不自动同步。APP 离线时仍可正常答题、判分、查看解析和生成复制文本。

## 实施顺序与验收

1. 先验证安卓长按选文、疑问高亮、公式整体标记、滚动与复制；同时验证 Windows 鼠标选文。依据结果确定可维护的框架与应用封装方式。
2. 再冻结题目、作答、标记和备份格式，搭建应用及本地存储。实现一轮示例题的完整流程。
3. 验证未完成不能判分、自评不得提前出现、答案锁定、正确统计、历史不覆盖、选文定位、异常退出恢复与备份恢复。
4. 分别交付并验证 Windows 程序和安卓 APK；手机/平板实机结果由用户反馈。浏览器窄屏测试不能代替安卓实机验收。

### 可选 DeepSeek 问答

在安卓应用的“更多 → DeepSeek 设置”填写API Key，保存后可检查连接、修改模型和输出上限或删除密钥。默认模型为deepseek-flash，依据[官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/)核对；[流式协议](https://api-docs.deepseek.com/api/create-chat-completion/)与[错误代码](https://api-docs.deepseek.com/quick_start/error_codes/)采用官方定义。首次提问需联网并使用用户API余额；不会自动重试已发送请求。达到长度上限、断网、超时或主动停止时保留部分回答，点击“继续这个问题”可编辑后重新预览发送。

在疑问标记上主动选择“问 AI”，预览要发送的题目背景和片段后才请求模型。Windows/平板侧栏和手机展开面板的具体形态通过原型确认。每条疑问有独立追问历史，回答本地保存；发送时不自动夹带整套题、其他疑问或全课程资料。

支持设备端配置与删除密钥、流式回答、取消、超时与失败提示、实际 token 用量显示。失败和中断不冒充回答完成；重试可能产生新费用。题库和作答仍以本地记录为准，不用 AI 判分替代客观评分。答题阶段默认不向 AI 提供标准答案和解析，AI解惑可能透露解题线索。

开启该模块会将预览的学习内容发送到 DeepSeek，并非完全离线。聊天备份不包含密钥；AI 模型名称和输出上限可配置，不写死价格或将估算冒充实际费用。安卓已实现原生HTTPS流式适配，固定使用官方地址https://api.deepseek.com，不经过本项目服务器。密钥由Android Keystore保护的AES-GCM加密存储，仅原生网络读取；设置页不回显已保存密钥，学习库、备份和网页存储不含密钥。用户在应用中自行填写，不发给开发者。当前未使用用户密钥做真实调用，不将模拟检查或构建当作API实测。

首版不做任意文档解析、账号系统、云同步、插件分发、AI 自动出题或整套知识笔记编辑系统。就地 AI 问答作为可选模块在本地流程可用后接入。以上是范围边界，不限制以后经用户授权扩展。
