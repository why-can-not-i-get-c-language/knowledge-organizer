# 知识梳理器

安卓本地学习应用：导入题集，逐题作答，查看解析，标记疑问，并可使用自己的 DeepSeek API Key 在应用内追问。题库、练习和问答保存在本机。

## 下载与安装

当前交付版本：**0.3.1，Android 7 及以上，仅 ARM64**。Windows 安装包尚未提供。

- [下载安装包](https://github.com/why-can-not-i-get-c-language/knowledge-organizer/raw/refs/heads/main/knowledge-organizer-0.3.1-arm64.apk)
- [源码压缩包](./knowledge-organizer-source-0.3.1.zip)
- [Agent 题集导入规范](./IMPORT_FOR_AGENT.md)

将 APK 下载到手机并按系统提示安装。升级时覆盖安装，不先卸载或清除应用数据。用户已反馈0.3.1中此前边缘返回后重开闪退未再出现；这不代表所有安卓设备均已验收。

## 使用

1. 准备符合规范的 JSON 题集，点“导入套题”；也可点“扫描题集”，首次允许系统文件访问后返回应用。扫描只能访问系统允许的公共存储，找不到时仍可手动导入。
2. 在左上角侧栏选择套题。开始一轮时选择逐题反馈或整套提交；每页一题，选项整行可点，进度自动保存。
3. 提交后查看正确答案、解析，再填写“理解了／仍不理解”。题干、选项、解析可选文标记；公式可整式标记。
4. 使用 AI 时，在“更多 → DeepSeek 设置”填写你自己的 API Key，保存并检查连接。标记后点“继续问”，输入问题 →“预览并发送”→“发送”。可选中旧回答继续追问，也可生成概括候选并手动采用。API 调用使用自己的账户余额，未配置或离线仍可做题。
5. 删除题库：进入该题库 →“更多 → 删除当前题库”，或在套题列表点“删除”。确认后同时删除它的练习、标记及问答；其他题库、API Key和原始JSON不受影响。
6. 定期在“更多”中导出备份；迁移设备时导入备份。备份不含 API Key。系统清除应用数据或卸载可能丢失本地记录。

## 让 AI 制作题集

把本仓库的 **IMPORT_FOR_AGENT.md 完整文件**，连同你的题目、答案与解析资料一起发给 AI，要求“严格按此规范生成可导入的 JSON 文件”。该规范自含字段、JSON Schema、三种题型示例、公式转义、版本规则和校验清单，不依赖历史对话或源码环境。

导入仅支持约定JSON，不直接导入PDF、Word、图片或任意聊天记录。文件格式合法不代表知识内容一定正确；请保留原始资料。个人课程题集、学习记录和密钥不随本仓库发布。
