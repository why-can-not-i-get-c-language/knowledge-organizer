# 知识梳理器

安卓本地学习应用：导入题集，逐题作答，查看解析，标记疑问，并可使用自己的 DeepSeek API Key 在应用内追问。题库、练习和问答保存在本机。

## 下载与安装

当前交付版本：**0.4.2，Android 7 及以上，仅 ARM64**。Windows 安装包尚未提供。

- [下载安装包](https://github.com/why-can-not-i-get-c-language/knowledge-organizer/raw/refs/heads/main/knowledge-organizer-0.4.2-arm64.apk)
- [源码压缩包](./knowledge-organizer-source-0.4.2.zip)
- [Agent 题集导入规范](./IMPORT_FOR_AGENT.md)

将 APK 下载到手机并按系统提示安装。升级时覆盖安装，不先卸载或清除应用数据。本版保留原包名与签名，可覆盖升级。0.4.2尚待手机安装与实测，请先在旧版导出备份。

## 使用

1. 准备符合规范的 JSON 题集，点“导入套题”；也可点“扫描题集”，首次允许系统文件访问后返回应用。扫描只能访问系统允许的公共存储，找不到时仍可手动导入。
2. 在左上角侧栏选择套题。开始一轮时选择逐题反馈或整套提交；每页一题，选项整行可点，进度自动保存。
3. 练习页实时显示已判分、答对、答错和不会数量；随时点“统计与错题”，查看本轮或历史轮次的错题、具体疑问、提问及草稿。整套提交前隐藏对错。
4. 不用逐题自评；直接点“这题我不会”，填写哪里不会，可只保存或继续问。该题标红并在向后切过三题后穿插重答；题目不足时在本轮结束前提示，也可稍后从统计中重答。答错再次安排，答对解除待重答状态；首次答案、错题记录和原因保留。不选答案而标记不会的题单列，不计入正确率。题干、选项、解析仍可选文标记，公式可整式标记。
5. 使用 AI 时，在“更多 → DeepSeek 设置”填写你自己的 API Key，保存并检查连接。标记后点“继续问”，输入问题 →“发送”。点面板外空白或顶部固定返回箭头可关闭面板，系统返回键始终先关闭最上层面板；侧栏也有固定返回箭头。连续提问后可用右侧索引跳转各段。可选中旧回答继续追问，也可生成概括候选并手动采用。API 调用使用自己的账户余额，未配置或离线仍可做题。
6. 删除题库：进入该题库 →“更多 → 删除当前题库”，或在套题列表点“删除”。确认后同时删除它的练习、标记及问答；其他题库、API Key和原始JSON不受影响。
7. 定期在“更多”中导出备份；迁移设备时导入备份。备份不含 API Key。系统清除应用数据或卸载可能丢失本地记录。

## 让 AI 制作题集

把本仓库的 **IMPORT_FOR_AGENT.md 完整文件**，连同你的题目、答案与解析资料一起发给 AI，要求“严格按此规范生成可导入的 JSON 文件”。该规范自含字段、JSON Schema、三种题型示例、公式转义、版本规则和校验清单，不依赖历史对话或源码环境。

导入仅支持约定JSON，不直接导入PDF、Word、图片或任意聊天记录。文件格式合法不代表知识内容一定正确；请保留原始资料。个人课程题集、学习记录和密钥不随本仓库发布。
